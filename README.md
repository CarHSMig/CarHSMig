### Projetos em destaque

#### 🎓 Presence: presença universitária com geolocalização e reconhecimento facial

Sistema completo em três serviços. O aluno confirma presença pelo celular, e a API só aceita quando o
horário, a localização e o rosto conferem.

| Repositório | Stack | Papel |
|---|---|---|
| [**presence**](https://github.com/CarHSMig/presence) | Rails 8 · PostgreSQL + pgvector · JWT · Pundit · ActionCable · RSpec | API central e regras de presença |
| [**Presence-FRONT**](https://github.com/CarHSMig/Presence-FRONT) | Next.js 16 · React 19 · Tailwind + shadcn/ui · TanStack | Painel administrativo e confirmação |
| [**Presence-face-recognition**](https://github.com/CarHSMig/Presence-face-recognition) | Python · FastAPI · InsightFace · pgvector · Docker | Embeddings e verificação facial |

#### 📊 [claude-usage](https://github.com/CarHSMig/claude-usage): app nativo de macOS

App de barra de menus em **Swift 6 / SwiftUI** que acompanha os limites de uso do Claude Code em várias
contas, indica a conta com mais folga e registra horas de IA por projeto. Testes com XCTest.

#### 🔗 Encurtador de URLs, em duas versões

- [**short-url**](https://github.com/CarHSMig/short-url): Node.js · Express · Sequelize · PostgreSQL · testes com Jest + Supertest
- [**ts-short-url**](https://github.com/CarHSMig/ts-short-url): reescrita em NestJS · TypeScript · TypeORM · Docker

#### 🏦 [APIbank](https://github.com/CarHSMig/APIbank): API bancária em Rails

Abertura de conta com validação de documento e idade, upload do documento com ActiveStorage e
transações de débito e crédito com controle de saldo.

#### Outros

- [**education-page**](https://github.com/CarHSMig/education-page): página educativa de matemática para crianças em Next.js + TypeScript.
- [**classes_unipar**](https://github.com/CarHSMig/classes_unipar): padrão State e um jogo de labirinto em Ruby puro.
